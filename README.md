## Featured projects

### [Comunidad Segura](https://github.com/ddesantiag0/comunidad-segura)

Bilingual React/TypeScript community-safety prototype with Firebase-backed incident reports, Leaflet maps, notifications, PWA support, and locally encrypted emergency-contact storage.

- Removed browser-exposed messaging credentials and routed optional SMS through a backend interface.
- Escaped report content used in map popups, removed fabricated fallback coordinates, and added route-level code splitting.
- Verified with 7 automated tests, ESLint, a production build, and a zero-vulnerability production dependency audit.

### [Secure Job Board API](https://github.com/ddesantiag0/secure-job-board-api)

Security-focused Express/MongoDB authentication API with bcrypt password hashing, JWT authorization, role-aware access, Helmet, configurable CORS, and request throttling.

- Prevents public users from assigning themselves the reserved administrator role.
- Validates and normalizes authentication input and separates app construction from database startup.
- Includes 6 request-level tests and a clean production dependency audit.

### [Wildfire Monitoring Drone](https://github.com/ddesantiag0/WildfireMonitoringDrone)

End-to-end Arduino and Node.js telemetry prototype for environmental/GPS readings transmitted through an ESP8266 AT interface.

- Sends structured readings as valid HTTP/JSON rather than raw socket fragments.
- Includes a dependency-free ground-station API, NDJSON logging, Leaflet dashboard, and hardware-free simulator.
- Ground-station tests and the live simulator path pass; physical hardware validation is documented as remaining work.

### [Splash Auto Detail](https://github.com/ddesantiag0/splash-auto-detail)

Responsive static website for a Chula Vista small business using semantic HTML, modern CSS, vanilla JavaScript, structured business data, a sitemap, and local-search documentation.

- Business information was checked against current public listings.
- Missing portfolio media and unsupported credential claims were replaced with truthful content.
- Static integrity tests cover local assets, section links, placeholder URLs, and structured data.
